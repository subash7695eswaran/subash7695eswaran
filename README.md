## 🚀 Featured Projects

### 🏦 Banfico – Mini Banking & Open Banking Consent Management System
**Stack:** Java 21 · Spring Boot 3 · React 18 (Vite) · PostgreSQL · Keycloak · Nginx · Docker

An enterprise-style banking system built for the Banfico University Full-Stack Developer Training & Selection Program, ending in an Open Banking consent capstone.

- Built a layered **Spring Boot REST API** for customers, bank accounts (IBAN generation), transactions (deposit / withdraw / transfer), and beneficiaries, documented with **Swagger / OpenAPI 3**
- Secured the platform with **Keycloak (OAuth2 / OpenID Connect)** and **JWT validation**, using realm roles for admin, maker, checker, and customer
- Implemented an **Open Banking consent lifecycle** — a TPP requests consent, which is approved or rejected, and data APIs are released only against an active, non-expired consent
- Created a **React dashboard** with live balances, statements, and interactive modals
- Put an **Nginx API gateway** in front of the full stack and orchestrated all services with **Docker Compose**; shipped a ready-to-import **Postman** collection

🔗 [View Repository](https://github.com/subash7695eswaran/banfico-banking-system)
